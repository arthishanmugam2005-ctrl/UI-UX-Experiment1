# UI-UX-Experiment1

## Aim:
To explore the fundamentals of UI (User Interface) and UX (User Experience), understand their differences using real-world case studies, analyze their relationship, and demonstrate various UI/UX design tools.
## Algorithm:
```
1.Study the basic concepts of User Interface (UI) and User Experience (UX). 2.Identify the key components of UI such as colors, typography, buttons, layout, and icons. 3.Identify UX elements like user research, wireframing, usability testing, and user journey mapping. 4.Analyze a real-world application (e.g., food delivery app) to differentiate UI and UX. 5.Observe how UI and UX work together to improve user satisfaction. 6.Explore popular UI/UX tools such as Figma, Adobe XD, Sketch, InVision, and Balsamiq. 7.Create a simple wireframe or interface using a UI/UX design tool. 8.Evaluate how the design improves user interaction and experience.

```

## Result:
The experiment was successfully completed. The fundamentals of UI and UX were studied, their differences were analyzed using real-world examples, their relationship in design was understood, and various UI/UX design tools were explored for practical implementation.
